[주요 기능 명세 및 아키텍처]
1. 쇼츠 콘텐츠 파이프라인 (Shorts Pipeline)
   - 스마트 대본 생성: 훅(Hook) - 본문 - 클로징 구조의 카테고리별 대본 자동 생성
   - 씬(Scene) 기반 자막 분할: 문장별 타이밍 및 자막 자동 생성
   - Web Speech Synthesis TTS 음성 합성 및 오디오 싱크 연동
   - Web Audio API 기반 배경음악(BGM) 자동 생성 및 볼륨 믹싱

2. 9:16 세로형 비디오 렌더링 엔진 (Canvas 2D Engine)
   - 해상도: 1080 x 1920 (9:16 FHD 세로 비율)
   - 모션 그래픽 비주얼: 입자 파티클, 동적 그라디언트, 네온 웨이브 배경
   - 사용자 미디어 업로드: 배경 이미지 및 동영상 커스텀 적용 지원
   - 시선 강탈 상단 타이틀 배너 및 상단/하단 진행 게이지 바(Progress Bar)
   - 틱톡/유튜브 쇼츠 트렌드 자막: 볼드체 외곽선, 팝업 바운스 애니메이션, 핵심어 하이라이트

3. 실시간 미리보기 및 녹화/다운로드 (MediaRecorder)
   - 스마트폰 목업 프레임을 통한 실시간 프리뷰
   - Canvas CaptureStream + Web Audio Stream 결합 녹화
   - 원클릭 고화질 비디오(.webm / .mp4) 다운로드
