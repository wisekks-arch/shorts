[주요 기능 명세 및 아키텍처]
1. 쇼츠 콘텐츠 파이프라인 (Shorts Pipeline)
   - 렌더링 시 실시간 TTS 음성 발화 및 화면/소리 동시 인코딩 파이프라인 (v2.6 New):
     * 렌더링 시작 시 실시간 라이브 재생 엔진(`startPlayback()`)과 비디오 캡처 레코더를 동기화 결합
     * 씬 전환 시마다 브라우저 한국어 TTS 실시간 발화(`triggerTTSForCurrentScene()`)를 자동 호출하여 사용자 스피커로 음성을 출력함과 동시에 캔버스 2D 화면과 마스터 오디오 스트림(BGM + SFX + 음성)을 동시 인코딩
     * 사용자가 보는 화면과 듣는 소리가 1:1로 일치하여 렌더링 진행 상황을 직관적으로 확인하고 비디오 파일에 100% 동시 반영
   - 모니터 세로 화면 최적화 컴팩트 레이아웃 (v2.5):
     * 다운로드 모달 50% 슬림화: 세로 스크롤 잘림 현상 방지를 위한 max-height(86vh) 잠금 및 내부 스크롤, 패딩/마진 대폭 압축
     * 저장 방식 3종 가로 3분할 콤팩트 그리드 개편: PC 폴더 저장 / 휴대폰 저장 / 빠른 다운로드를 가로 3열 슬림 퀵 카드로 재구성하여 세로 공간 75% 절약
     * 메인 화면 세로 컴팩트 다이어트: 헤더 높이 48px 축소, 탭/폼 여백 축소, 폰 목업 프리뷰 세로 높이(515px) 반응형 최적화로 모니터 한 화면에 스크롤 없이 100% 안착
   - 작업 히스토리 저장관리 및 복원 시스템 (v2.4):
     * 전 작업 히스토리 스냅샷 보관: 1.대본기획, 2.배경/비쥬얼 미디어 풀(Base64 이미지/비디오), 3.쇼츠자막 스타일, 4.오디오 믹싱 전체 상태 보관
     * 어제/이전 작업 불러오기(수정/개선): 타임라인 목록에서 클릭 한 번으로 모든 편집 상태 100% 복원
     * 실시간 자동 저장(Auto-save) 및 JSON 백업 파일 내보내기/가져오기 지원
   - 내장 신디사이저 BGM 테마 10종 확충 (v2.4):
     * 10가지 맞춤형 Web Audio 사운드 프리셋 탑재 (로파이 힙합, 신스웨이브, 사이버펑크, 어쿠스틱 드림, 업비트 팝, 미스터리 앰비언트, 긴장 스릴러, 쇼츠 트랩, 피아노 무드, 시네마틱 에픽)
     * 오실레이터 파형(sine, triangle, sawtooth, square), 아르페지오 및 서브베이스 동시 합성
   - 브라우저 TTS 실시간 음성 비디오 저장 파이프라인 (v2.3):
     * 브라우저 TTS 음성 다이렉트 캡처 녹화: 브라우저 표준 사운드 루프백(`getDisplayMedia({ audio: true })`)을 통해 대본을 읽어주는 브라우저 TTS 한국어 음성과 BGM을 100% 디지털로 캡처하여 비디오 파일에 실시간 녹화 및 영구 저장
     * 다운로드 모달 [🔊 브라우저 TTS 실시간 음성 포함 다운로드] 기본 권장 옵션 신설 및 원클릭 녹화 시작
   - 배경음(BGM) & 나레이션 멘트 동시 믹싱 기본옵션 파이프라인 (v2.2):
     * 배경음과 나레이션 동시 믹싱 녹음: Web Audio API 기반 마이크 입력 노드와 BGM 노드를 결합한 통합 레코딩 스트림 구축 (스튜디오급 듀얼 오디오 동시 녹음)
     * 오디오 덕킹 밸런스(Auto Ducking): 나레이션 목소리가 선명하게 들리도록 배경음 30%, 나레이션 100% 볼륨 자동 최적 밸런싱
   - 나레이션 멘트 합성 스마트 인터셉터 및 동기화 파이프라인 (v2.1):
     * 다운로드 시 나레이션 멘트 미등록 방지 스마트 가이드 탑재: 비디오 다운로드 클릭 시 음성 미등록 경고 및 원클릭 마이크 녹음 숏컷 제공
     * 플로팅 실시간 녹음 바: 화면 상단에 녹음 진행 상태 및 원클릭 녹음 완료 바 제공
   - 커스텀 타이포그래피 & 실시간 마이크 나레이션 녹음 엔진 (v2.0):
     * 폰트 위치: 퀵 프리셋(상단 22%, 중앙 50%, 하단 70%) 및 15%~85% 정밀 세로축(Y) 슬라이더
     * 폰트 크기: 36px ~ 120px 실시간 가변 조절
     * 부분 폰트(강조) 색상: 가라오케 단어별 강조 색상 선택기
     * 기본 폰트 색상 & 외곽선 테두리: 기본 폰트 컬러 및 테두리 두께(0~24px)와 외곽선 색상 조절
   - 마스터 오디오 녹음 및 렌더링 동기화 엔진 개선 (v1.9): 비디오 렌더링 시 배경음악(BGM) 차단 버그 해결(`isExporting` 플래그), `audioCtx.resume()` 강제 활성화
   - 인기 카테고리 템플릿 확충 (v1.8): 음식점/핫플 안내 시나리오 2종 추가 ([신규 오픈 안내 & 장소 소개], [시그니처 대표 메뉴 소개])
   - 다운로드 저장 경로 및 파일명 지정 UI (v1.7): 비디오 다운로드 클릭 시 저장 파일명 직접 지정 및 PC 폴더 직접 선택(File System Access API) / 모바일 내 파일 앱 및 공유(Web Share API)
   - 모바일/PC 크로스 플랫폼 최적화 (v1.6): 스마트폰 및 PC 접속 시 화면 자동 반응형 레이아웃, 모바일 뷰 전환 모드
   - 목표 동영상 플레이 시간 사전 세팅: 30초 / 1분 / 2분 / 3분 / 5분 / 자동 선택 옵션 및 스마트 타임라인 비례 배분 엔진 탑재
   - 스마트 대본 생성: 훅(Hook) - 본문 - 클로징 구조의 카테고리별 대본 자동 생성 (지식, 신규맛집, 대표메뉴, 동기부여, 꿀팁, 재테크, 심리, 지원금 8종)

2. 9:16 세로형 비디오 렌더링 엔진 (Canvas 2D Engine)
   - 해상도: 1080 x 1920 (9:16 FHD 세로 비율)
   - 다중 미디어 풀(Media Pool): 동영상 최대 5개, 이미지 최대 20개 동시 등록 및 관리 갤러리
   - 씬(Scene)별 미디어 자동 순차 전환 및 씬 카드별 개별 배경 매칭 지원
   - 이미지 켄 번스(Ken Burns) 카메라 모션 줌(1.0x -> 1.15x) 효과 적용
   - 모션 그래픽 비주얼: 오로라 네뷸라, 사이버 펄스, 네온 파티클, 마그마 플레임 등
   - 쇼츠 트렌드 가라오케 자막: 단어별 실시간 하이라이트, 팝업 바운스 줌

3. 실시간 미리보기 및 녹화/다운로드 (MediaRecorder)
   - 스마트폰 목업 프레임을 통한 실시간 프리뷰
   - Canvas CaptureStream + Master Audio Stream (BGM + 나레이션 + SFX) 결합 녹화
   - 원클릭 고화질 비디오(.webm) 다운로드 및 썸네일(JPG) 캡처
