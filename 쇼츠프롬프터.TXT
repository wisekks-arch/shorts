[주요 기능 명세 및 아키텍처]
1. 쇼츠 콘텐츠 파이프라인 (Shorts Pipeline)
   - [🔊 TTS 저장] 배경음 제외 순수 TTS 음성 전용 추출/저장 기능 추가 (v2.12 New):
     * `📸 썸네일(JPG)` 버튼 옆에 `[🔊 TTS 저장]` 버튼 추가
     * 클릭 시 BGM(배경음악) 및 SFX(효과음)를 완전히 제외한 상태에서 화면이 씬별로 넘어가며 순수 TTS 목소리만 녹음하여 파일(`TTS_*.webm`)로 저장
     * 저장과 동시에 추출된 TTS 음성을 현재 프로젝트 나레이션 트랙(`customVoiceAudio`)에 자동 적용하여 이후 비디오 다운로드 시 BGM과 100% 완벽 믹싱 지원
   - 다운로드 모달 통합 및 TTS 오디오 누락 원천 차단 (v2.11):
     * 중복 분리되어 혼란을 주던 상단 `[TTS 음성 포함 실시간 녹화 시작 (PC 저장)]` 별도 버튼을 제거하고, `☑️ TTS 음성 + 배경음(BGM) 동시 녹음 (기본 적용)` 체크박스로 통합
     * 하단 `[PC 폴더 선택]`, `[휴대폰 저장]`, `[빠른 저장]` 어느 저장 방식을 누르더라도 TTS 목소리 + BGM 동시 녹음이 일관되게 적용됨
     * 실서버 공유 창에서 `[전체 화면]` 및 `[시스템 오디오도 공유]`가 누락된 경우 즉시 재선택 확인창(`confirm`)을 띄워 무음 저장을 원천 방지
   - 화면 공유 오디오 조기 중단 버그 해결 및 로컬 다이렉트 TTS 믹싱 구현 (v2.10):
     * `startTTSRecordExport`에서 녹화 시작 전 `vTracks.forEach(t => t.stop())` 조기 호출로 Chrome이 오디오 캡처를 중단하던 치명적 버그 제거 (녹화 종료 `recorder.onstop` 시점에 일괄 종료)
     * 로컬 서버(`server.ps1`) 실행 시 `/api/tts` 엔드포인트로 Windows 내장 한국어 TTS WAV를 즉시 생성해 공유 팝업 없이도 Web Audio에 100% 직접 믹싱
   - 시스템 오디오 기반 브라우저 TTS 100% 믹싱 녹화 복원 (v2.9):
     * Windows OS TTS(`Microsoft Heami`) 음성이 탭 오디오가 아닌 시스템 오디오로 출력되는 구조에 맞춰 `preferCurrentTab` 제한을 제거하고 `[전체 화면]` + `[시스템 오디오도 공유]` 캡처가 정상 작동하도록 복원
     * 공유 선택 상태(`displaySurface === 'monitor'`) 검증 및 미충족 시 즉시 안내 경고 추가
   - 모든 다운로드 경로 TTS 음성 믹싱 자동 통합 파이프라인 (v2.8):
     * 사용자 음성(마이크/MP3) 미등록 시 PC 폴더 선택 / 휴대폰 저장 / 빠른 저장 등 모든 다운로드 버튼에서 자동으로 브라우저 TTS 실시간 오디오 루프백 캡처(`getDisplayMedia`, `preferCurrentTab: true`)가 연동되어 TTS 목소리와 BGM/SFX가 100% 함께 믹싱 녹음됨
     * 마이크 녹음 중 다운로드 실행 시 녹음 상태 자동 정리로 충돌 방지
     * 렌더링 중 씬 전환 TTS 중복 발화 제거(단일 `playbackLoop` 일원화)로 또렷한 한국어 발음 보장
   - 조작 및 기능 설명 줄 [안내] 표준 표기 일괄 적용 (v2.7):
     * 모든 탭(1.대본기획, 2.배경/비주얼, 3.쇼츠자막, 4.오디오믹싱) 및 팝업 모달(다운로드, 히스토리)의 조작/기능 설명 줄에 `[안내]` 태그를 일관되게 적용
     * 기능 명칭, 버튼, 입력 컨트롤의 고유 모드는 온전히 유지하면서 부가 안내 가이드의 직관성과 가독성 극대화
   - 렌더링 시 실시간 TTS 음성 발화 및 화면/소리 동시 인코딩 파이프라인 (v2.6):
     * 렌더링 시작 시 실시간 라이브 재생 엔진(`startPlayback()`)과 비디오 캡처 레코더를 동기화 결합
     * 씬 전환 시마다 브라우저 한국어 TTS 실시간 발화(`triggerTTSForCurrentScene()`)를 자동 호출하여 사용자 스피커로 음성을 출력함과 동시에 캔버스 2D 화면과 마스터 오디오 스트림(BGM + SFX + 음성)을 동시 인코딩
   - 모니터 세로 화면 최적화 컴팩트 레이아웃 (v2.5):
     * 다운로드 모달 50% 슬림화, 저장 방식 3종 가로 3분할 콤팩트 그리드 개편, 폰 목업 프리뷰 세로 높이(515px) 반응형 최적화
   - 작업 히스토리 저장관리 및 복원 시스템 (v2.4):
     * 1.대본기획, 2.배경/비쥬얼 미디어 풀(Base64 이미지/비디오), 3.쇼츠자막 스타일, 4.오디오 믹싱 전체 상태 보관 및 클릭 한 번으로 복원
   - 내장 신디사이저 BGM 테마 10종 확충 (v2.4):
     * 10가지 맞춤형 Web Audio 사운드 프리셋 탑재 (로파이 힙합, 신스웨이브, 사이버펑크, 어쿠스틱 드림, 업비트 팝, 미스터리 앰비언트, 긴장 스릴러, 쇼츠 트랩, 피아노 무드, 시네마틱 에픽)
   - 브라우저 TTS 실시간 음성 비디오 저장 파이프라인 (v2.3):
     * 브라우저 표준 사운드 루프백(`getDisplayMedia({ audio: true })`)을 통해 대본을 읽어주는 브라우저 TTS 한국어 음성과 BGM을 100% 디지털로 캡처하여 비디오 파일에 실시간 녹화 및 영구 저장
   - 배경음(BGM) & 나레이션 멘트 동시 믹싱 기본옵션 파이프라인 (v2.2):
     * Web Audio API 기반 마이크 입력 노드와 BGM 노드를 결합한 통합 레코딩 스트림 구축 및 오디오 덕킹 밸런스(Auto Ducking)
   - 커스텀 타이포그래피 & 실시간 마이크 나레이션 녹음 엔진 (v2.0)
   - 목표 동영상 플레이 시간 사전 세팅 (30초 / 1분 / 2분 / 3분 / 5분 / 자동)

2. 9:16 세로형 비디오 렌더링 엔진 (Canvas 2D Engine)
   - 해상도: 1080 x 1920 (9:16 FHD 세로 비율)
   - 다중 미디어 풀(Media Pool): 동영상 최대 5개, 이미지 최대 20개 동시 등록 및 관리 갤러리
   - 이미지 켄 번스(Ken Burns) 카메라 모션 줌(1.0x -> 1.15x) 효과 및 가라오케 자막

3. 실시간 미리보기 및 녹화/다운로드 (MediaRecorder)
   - 스마트폰 목업 프레임을 통한 실시간 프리뷰
   - 원클릭 고화질 비디오(.webm) 다운로드 및 썸네일(JPG) 캡처
