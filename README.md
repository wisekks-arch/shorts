# 유튜브 쇼츠 자동생성기 (ShortsMaker) v2.11

> 웹 브라우저 상에서 원클릭으로 9:16 세로형 유튜브 쇼츠(Shorts) 영상을 기획, 제작, 렌더링 및 다운로드하는 자동화 파이프라인 웹 애플리케이션입니다. 어떤 다운로드 방식을 선택하더라도 브라우저 TTS 목소리와 BGM/SFX가 100% 함께 믹싱 녹음되며, 모든 안내 문구에 `[안내]` 표준 표기가 적용되어 있습니다.

## 🚀 주요 기능 명세 (v2.8 Full TTS Audio Mixing & Unified Export)

### 1. 모든 다운로드 경로 TTS 음성 자동 믹싱 통합 - New!
* **어떤 저장 방식을 눌러도 TTS 목소리 포함 저장**:
  * 별도 음성(마이크/MP3)을 등록하지 않은 상태에서 `PC 폴더 선택`, `휴대폰 저장`, `빠른 저장` 등 어떤 다운로드 옵션을 선택하더라도 자동으로 현재 탭 오디오 캡처(`preferCurrentTab: true`)가 연동되어 **한국어 TTS 목소리 + BGM + SFX가 100% 함께 믹싱 녹음**됩니다.
* **음성 끊김 없는 단일 재생 루프 및 마이크 녹음 충돌 방지**:
  * 중복 TTS 호출을 제거하여 씬별 음성이 또렷하게 발화되며, 마이크 녹음 중 다운로드 시작 시 안전하게 정리 후 렌더링을 진행합니다.

### 2. 조작 및 기능 설명 줄 [안내] 표준 표기 일괄 적용
* 모든 탭과 모달의 부가 설명 텍스트에 `[안내]` 표기를 일관되게 적용하여 가독성과 직관성을 높였습니다.

### 3. 모니터 화면 맞춤 컴팩트 세로 레이아웃 & 작업 히스토리 시스템
* 다운로드 모달 50% 슬림화, 저장 방식 가로 3열 퀵 그리드, 폰 목업 세로 최적화(515px) 적용.
* 대본, 미디어 풀, 자막 스타일, 오디오 믹싱 상태를 히스토리로 저장하고 언제든 불러와 수정 가능.
