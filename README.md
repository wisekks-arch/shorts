## 🚀 주요 기능 명세 (v2.4 고도화)

### 1. 작업 히스토리 저장 관리 및 복원(재수정) 시스템 - New!
* **전체 작업 스냅샷 보관**:
  * 1. 대본기획 (씬 목록 및 타임라인)
  * 2. 배경/비쥬얼 첨부 파일 (등록된 미디어 풀 이미지/동영상 Base64 데이터)
  * 3. 쇼츠자막 스타일 (폰트 위치, 크기, 가라오케 부분강조색, 기본색, 외곽선 테두리)
  * 4. 오디오 믹싱 (BGM 테마, 볼륨, SFX, 나레이션 음성 파일)
* **어제 작업한 내용 불러오기 (수정/개선)**:
  * 상단 헤더의 **`[📂 작업 히스토리]`**를 열어 이전 프로젝트 카드의 **`[📂 불러오기]`** 버튼을 클릭하면, 당시의 모든 상태가 100% 복원되어 즉시 이어서 편집할 수 있습니다.
* **실시간 자동 저장(Auto-save) 및 백업 지원**:
  * 20초마다 자동 보관되어 브라우저를 재접속해도 복원 가능하며, JSON 파일 백업 다운로드/불러오기를 지원합니다.

### 2. 내장 신디사이저 BGM 테마 10종 확충 - New!
* 쇼츠 분위기에 맞춘 10가지 Web Audio 사운드 프리셋 탑재:
  1. 🎧 **감각적인 로파이 힙합 (Lo-Fi Chill)**
  2. ⚡ **네온 레트로 신스웨이브 (Synthwave)**
  3. 🌃 **다크 사이버펑크 디스토피아 (Cyberpunk)**
  4. 🎸 **감성 어쿠스틱 드림 & 힐링 (Acoustic)**
  5. 🕺 **활기찬 업비트 팝 댄스 (Upbeat Pop)**
  6. 🌌 **미스터리 심해 앰비언트 (Mystery Ambient)**
  7. 🚨 **긴장감 넘치는 스릴러 체이서 (Tension Chaser)**
  8. 💣 **에너제틱 숏폼 트랩 비트 (Shorts Trap)**
  9. 🎹 **감미로운 네오클래식 피아노 (Piano Mood)**
  10. 🎬 **웅장한 블록버스터 에픽 (Cinematic Epic)**

### 3. 브라우저 TTS 실시간 음성 비디오 저장 파이프라인
* 브라우저 표준 사운드 루프백(`getDisplayMedia({ audio: true })`)을 통해 대본을 읽어주는 브라우저 TTS 한국어 음성과 BGM을 100% 디지털로 캡처하여 비디오 파일에 실시간 녹화 및 영구 저장합니다.

### 4. 배경음(BGM) & 나레이션 멘트 동시 믹싱
* 마이크 녹음 시 브라우저에서 흘러나오는 BGM과 사용자의 목소리가 Web Audio 노드 상에서 하나의 통합 스트림으로 묶여 스튜디오급으로 동시 녹음됩니다.
* 오디오 덕킹(Auto Ducking)으로 배경음 30%, 나레이션 100% 볼륨 자동 최적 밸런싱을 제공합니다.

### 5. 자막 폰트 위치, 크기, 부분 폰트 색상 정밀 커스텀
* **📍 폰트 세로 위치 (Y축) 자유 이동**: 퀵 버튼(상단 22%, 중앙 50%, 하단 70%) 및 15%~85% 정밀 슬라이더
* **📏 폰트 크기 조절**: 36px ~ 120px 실시간 가변 슬라이더
* **🌟 부분 폰트(가라오케 하이라이트) 색상 변경**: 현재 읽는 단어 강조 컬러칩 5종 및 커스텀 컬러 피커
* **⚪ 기본 텍스트 색상 & ⬛ 외곽선 테두리**: 텍스트 컬러 선택 및 외곽선 테두리 두께(0~24px)와 색상 조절

### 6. 음식점 전문 쇼츠 시나리오 2종
* 🍽️ 신규 오픈 맛집 안내 (장소/위치, 오픈 할인 이벤트)
* 🥩 시그니처 대표 메뉴 소개 (비주얼/식감 묘사, 품절 주의 훅)

### 7. 다운로드 경로 및 파일명 직접 지정 UI
