## 🚀 주요 기능 명세

### 1. 스마트 대본 자동 생성 (Script Pipeline)
* **인기 카테고리 템플릿**: 흥미로운 상식, 인생 명언/동기부여, 생활 꿀팁, 미스터리 사건, 충격적인 진실
* **3초 훅(Hook) 구조화**: 시청 지속시간(Audience Retention)을 극대화하는 도입부-본론-결론 자동 구성
* **씬(Scene) 자동 분할**: 대본을 문장 단위로 파싱하여 자막 타임라인을 자동 생성

### 2. 세로형 9:16 모션 비주얼 엔진 (Canvas 2D Engine)
* **1080 x 1920 해상도**: 유튜브 쇼츠 최적화 규격
* **다이내믹 배경 이펙트**: 오로라 그라디언트, 네온 파티클, 펄스 웨이브 등 시각적 몰입도 높은 모션 그래픽
* **커스텀 미디어 지원**: 사용자가 직접 보유한 이미지나 비디오를 배경으로 지정 가능
* **유튜브 쇼츠형 자막**: 두꺼운 고딕 폰트, 외곽선(Stroke), 단어별 바운스 줌 및 하이라이트 효과
* **진행 바(Progress Bar) & 헤드라인 배너**: 영상 상단 시선 고정 타이틀 및 하단 시간 진행 바

### 3. 음성 합성(TTS) 및 오디오 믹싱
* **Web Speech Synthesis API**: 자연스러운 한국어 나레이션 음성 자동 생성 (속도, 톤 제어)
* **내장 BGM 합성 엔진**: Web Audio API 기반의 비트/앰비언트 배경음악 생성 및 음량 조절
* **외부 오디오 지원**: 사용자 배경음악 파일 업로드 지원

### 4. 실시간 프리뷰 & 원클릭 비디오 다운로드
* **스마트폰 목업 뷰**: 실제 모바일 쇼츠 화면과 동일한 환경에서 실시간 재생/미리보기
* **MediaRecorder 브라우저 렌더링**: Canvas 화면과 Audio 스트림을 결합하여 고화질 영상 파일 즉시 추출 및 다운로드
