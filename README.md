## 🚀 주요 기능 명세 (v1.2 고도화)

### 1. 스마트 대본 자동 생성 (Script Pipeline)
* **인기 카테고리 템플릿**: 뇌/인체의 비밀(상식), 5초 결단(동기부여), 아침 커피의 함정(꿀팁), 부자들의 통장 규칙(재테크), 상대방 심리 간파법(심리학), 숨은 정부 지원금(정보이슈)
* **3초 훅(Hook) 구조화**: 시청 지속시간(Audience Retention)을 극대화하는 도입부-본론-결론 자동 구성
* **씬(Scene) 타임라인 편집**: 씬 추가/삭제, 문장 및 지속시간(초) 미세조정 UI 제공

### 2. 세로형 9:16 모션 비주얼 엔진 (Canvas 2D Engine)
* **1080 x 1920 해상도**: 유튜브 쇼츠 최적화 규격
* **다이내믹 배경 이펙트**: 오로라 네뷸라, 사이버 펄스, 네온 파티클, 마그마 플레임, 매트릭스 스트림, 모던 다크 미니멀
* **커스텀 미디어 지원**: 사용자가 직접 보유한 이미지나 비디오를 배경으로 지정 가능
* **가라오케 단어별 하이라이트 자막**: 현재 읽히는 단어에 실시간 형광 노랑 하이라이트 부여 (최신 인기 쇼츠 트렌드)
* **진행 바(Progress Bar) & 헤드라인 배너**: 영상 상단 시선 고정 타이틀 및 상단 시간 진행 게이지 바

### 3. 마스터 오디오 믹싱 시스템
* **나레이션 오디오 업로드 슬롯**: 클로바더빙, 타입캐스트, Vrew 등 외부 TTS 오디오(.mp3) 업로드 시 비디오 파일에 100% 결합 합성
* **Web Speech Synthesis API**: 브라우저 실시간 한국어 TTS 음성 프리뷰
* **내장 BGM 합성 엔진**: Web Audio API 기반의 비트/앰비언트 배경음악 생성 및 음량 조절
* **효과음(SFX) 엔진**: 씬 전환 시 'Whoosh', 자막 등장 시 'Pop' 효과음 자동 믹싱

### 4. 실시간 프리뷰 & 원클릭 비디오 다운로드
* **스마트폰 목업 뷰**: 실제 모바일 쇼츠 화면과 동일한 환경에서 실시간 재생/미리보기
* **MediaRecorder 브라우저 렌더링**: Canvas 비디오 + Master Audio 스트림을 결합하여 고화질 영상 파일(`.webm`) 즉시 추출 및 다운로드
* **썸네일 캡처**: 쇼츠 업로드용 1080x1920 고화질 썸네일(JPG) 원클릭 저장
