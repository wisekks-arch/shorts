# 유튜브 쇼츠 자동 제작기 (ShortsMaker) v2.0 Custom Typography & Mic Voice

> 웹 브라우저 상에서 원클릭으로 9:16 세로형 유튜브 쇼츠(Shorts) 영상을 기획, 제작, 렌더링 및 다운로드하는 자동화 파이프라인 웹 애플리케이션입니다. 폰트 위치, 크기, 부분 강조 색상을 자유롭게 변경할 수 있으며, 원클릭 마이크 나레이션 녹음 기능을 통해 비디오 파일에 내 목소리가 100% 합성되어 다운로드됩니다.

---

## 📌 프로젝트 개요
* **프로젝트명**: 유튜브 쇼츠 자동 제작기 (ShortsMaker)
* **저장소 위치**: `D:\92.SW\shorts`
* **로컬 접속 주소**: `http://localhost:5050`
* **실서버 배포 주소**: `https://wisekks-arch.github.io/shorts/index.html`
* **프롬프터 파일**: `쇼츠프롬프터.TXT` (UTF-8)

---

## 🚀 주요 기능 명세 (v2.0 Custom Typography & Mic Voice 메이저 업데이트)

### 1. 자막 폰트 위치, 크기, 부분 폰트 색상 정밀 커스터마이징 - New!
* **📍 폰트 세로 위치 (Y축) 자유 조절**:
  * 퀵 버튼: `[⬆️ 상단 (22%)]` `[⏺️ 중앙 (50%)]` `[⬇️ 하단 (70%)]`
  * 정밀 슬라이더: `15% ~ 85%` 범위 내에서 원하는 위치로 미세 조정
* **📏 폰트 크기 조절**:
  * `36px ~ 120px` 가변 슬라이더 (실시간 캔버스 즉각 반영)
* **🎨 부분 폰트(가라오케 하이라이트) 색상 변경**:
  * 현재 읽고 있는 단어의 강조 색상을 퀵 컬러칩(형광노랑, 네온핑크, 네온시안, 라임그린, 오렌지) 및 커스텀 컬러 피커로 자유롭게 선택
* **⚪ 기본 텍스트 색상 & ⬛ 외곽선 테두리**:
  * 기본 자막 텍스트 컬러 선택 및 외곽선 테두리 두께(0~24px)와 색상 조절로 영상 위 가독성 극대화

### 2. 실시간 마이크 나레이션 원클릭 녹음 & 비디오 100% 합성 - New!
* **🎙️ 원클릭 마이크 녹음기 탑재**:
  * 외부 사이트나 별도 파일 없이, `[🎙️ 내 목소리로 바로 녹음]`을 누르면 쇼츠 재생과 함께 마이크로 낭독한 음성이 즉시 캡처되어 비디오에 1:1 완벽 합성
* **📢 나레이션 음원 상태 스마트 대시보드 & 모달 안내**:
  * 대본 탭 및 다운로드 모달에서 나레이션 음성 포함 여부를 실시간으로 표시하고, 미등록 시 마이크 즉시 녹음 숏컷 제공

### 3. 비디오 렌더링 마스터 오디오 스트림 합성
* 신스 BGM 비트/앰비언트 루프 및 씬 전환 효과음(Whoosh, Pop) 결합
* `audioBitsPerSecond: 128000` 고음질 인코딩

### 4. 음식점 전문 쇼츠 시나리오 2종
* 🍽️ 신규 오픈 맛집 안내 (장소/위치, 오픈 할인 이벤트)
* 🥩 시그니처 대표 메뉴 소개 (비주얼/식감 묘사, 품절 주의 훅)

### 5. 다운로드 경로 및 파일명 직접 지정 UI
* 💻 PC 파일 탐색기 저장 폴더(경로) 직접 선택 (`showSaveFilePicker`)
* 📱 모바일 '내 파일/파일 앱/클라우드' 저장 연동 (`navigator.share`)
