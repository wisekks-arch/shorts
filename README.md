# 유튜브 쇼츠 자동생성기 (ShortsMaker) v2.5 Compact Layout

> 웹 브라우저 상에서 원클릭으로 9:16 세로형 유튜브 쇼츠(Shorts) 영상을 기획, 제작, 렌더링 및 다운로드하는 자동화 파이프라인 웹 애플리케이션입니다. 모니터 화면에서 위아래가 잘리지 않도록 전체 세로 사이즈를 대폭 다이어트하여 스크롤 없이 쾌적하게 쇼츠를 제작할 수 있습니다.

## 🚀 주요 기능 명세 (v2.5 Compact Layout 고도화)

### 1. 모니터 화면 맞춤 컴팩트 세로 레이아웃 - New!
* **다운로드 모달 50% 슬림화**:
  * 세로 스크롤 잘림을 방지하기 위해 `max-height: 86vh` 잠금 및 내부 안전 스크롤을 적용하고, 내부 여백을 컴팩트하게 압축하였습니다.
* **저장 위치 3종 가로 3분할 콤팩트 그리드 개편**:
  * 기존 세로 나열 방식 ➔ **가로 3열 퀵 버튼(PC 폴더 선택, 휴대폰 저장, 빠른 저장)**으로 재구성하여 세로 공간을 75% 절약하였습니다.
* **메인 작업 화면 및 폰 목업 세로 최적화**:
  * 상단 헤더 높이를 48px로 슬림화하고, 폰 목업 프리뷰 세로 길이를 515px로 반응형 최적화하여 1080p 및 노트북 화면에서도 스크롤 없이 재생/다운로드 버튼까지 한눈에 표시됩니다.

### 2. 작업 히스토리 저장 관리 및 복원(재수정) 시스템
* **전체 작업 스냅샷 보관**:
  * 1. 대본기획 (씬 목록 및 타임라인)
  * 2. 배경/비쥬얼 첨부 파일 (등록된 미디어 풀 이미지/동영상 Base64 데이터)
  * 3. 쇼츠자막 스타일 (폰트 위치, 크기, 가라오케 부분강조색, 기본색, 외곽선 테두리)
  * 4. 오디오 믹싱 (BGM 테마, 볼륨, SFX, 나레이션 음성 파일)
* **어제 작업한 내용 불러오기 (수정/개선)**:
  * 상단 헤더의 **`[📂 작업 히스토리]`**를 열어 이전 프로젝트 카드의 **`[📂 불러오기]`** 버튼을 클릭하면, 당시의 모든 상태가 100% 복원되어 즉시 이어서 편집할 수 있습니다.

### 3. 내장 신디사이저 BGM 테마 10종 확충
* 쇼츠 분위기에 맞춘 10가지 Web Audio 사운드 프리셋 탑재 (로파이 힙합, 신스웨이브, 사이버펑크, 어쿠스틱 드림, 업비트 팝, 미스터리 앰비언트, 긴장 스릴러, 쇼츠 트랩, 피아노 무드, 시네마틱 에픽)

### 4. 브라우저 TTS 실시간 음성 비디오 저장 파이프라인
* 브라우저 표준 사운드 루프백(`getDisplayMedia({ audio: true })`)을 통해 대본을 읽어주는 브라우저 TTS 한국어 음성과 BGM을 100% 디지털로 캡처하여 비디오 파일에 실시간 녹화 및 영구 저장합니다.

### 5. 배경음(BGM) & 나레이션 멘트 동시 믹싱
* 마이크 녹음 시 브라우저에서 흘러나오는 BGM과 사용자의 목소리가 Web Audio 노드 상에서 하나의 통합 스트림으로 묶여 스튜디오급으로 동시 녹음됩니다.
