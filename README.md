## 🚀 주요 기능 명세 (v1.7 Save Picker 고도화)

### 1. 다운로드 경로 및 파일명 직접 지정 UI - New!
* **저장 파일명 커스텀**:
  * 원하는 비디오 파일명을 직접 입력하거나 대본 키워드 기반 자동 생성 파일명 적용
* **3가지 저장 방식 선택 모달**:
  * 💻 **저장 폴더(경로) 직접 선택 (PC 권장)**: File System Access API(`showSaveFilePicker`)를 연동하여 Windows 파일 탐색기 저장 대화상자가 열리고, 사용자가 원하는 드라이브/폴더(바탕화면, D드라이브, 특정 작업 폴더 등)를 직접 지정하여 저장
  * 📱 **휴대폰 저장 위치 / 앱 선택 (모바일 권장)**: Web Share API(`navigator.share`)를 연동하여 스마트폰의 '파일에 저장(내 파일 앱)', Google Drive, 클라우드 등 원하는 저장 위치를 직접 선택
  * 📥 **기본 다운로드 폴더로 바로 저장**: 별도 경로 선택 없이 브라우저 기본 Downloads 폴더로 즉시 빠른 저장

### 2. 스마트폰 / PC 크로스 플랫폼 완벽 반응형 UI
* **모바일 최적화 레이아웃 (`@media (max-width: 960px)`)**:
  * 데스크톱 PC 접속 시: 좌측 대본/옵션 컨트롤 패널 + 우측 스마트폰 목업 실시간 미리보기 (2열 와이드 뷰)
  * 스마트폰/태블릿 모바일 접속 시: 상단 플로팅 뷰 전환 탭(`[⚙️ 설정 및 편집] ↔ [📱 쇼츠 미리보기]`)을 통해 한 화면에서 쾌적하게 조작 가능
* **터치 친화적 컨트롤 & 모바일 미리보기 프레임**:
  * 모바일 작은 화면에서도 가라오케 프리뷰가 잘리지 않고 화면 너비에 맞게 동적 스케일링(Scale)

### 3. 목표 동영상 플레이 시간 사전 세팅 (Duration Controller)
* **선택 옵션 6종**:
  * ⚡ **30초** (초고속 임팩트 숏폼)
  * ⏱️ **1분 / 60초** (클래식 유튜브 쇼츠 표준)
  * 🎬 **2분 / 120초** (스토리텔링 쇼츠)
  * 📽️ **3분 / 180초** (최신 유튜브 쇼츠 최대 규격)
  * 📺 **5분 / 300초** (미드폼/정보형 영상)
  * 🔄 **자동** (대본 글자 수 맞춤 계산)
* **스마트 타임라인 자동 스케일링**: 시간을 선택하면 모든 씬의 지속시간이 글자 수 비율에 맞추어 정확히 목표 시간에 도달하도록 자동 비례 배분 및 오차 보정

### 4. 원클릭 올인원(All-in-One) 통합 미디어 업로더
* **단 한 번의 파일 선택으로 동시 등록**: `accept="image/*,video/*" multiple` 지원
* **스마트 자동 분류 엔진**: 파일 탐색기에서 사진(최대 20개)과 동영상(최대 5개)을 한 번에 다중 선택(`Ctrl`/`Shift`/드래그)하면 파일 타입을 자동 판별하여 각각의 풀로 자동 배분
* **실시간 대시보드 배너**: 2번 탭 상단에 시인성 높은 현황 카드(`📷 이미지 X/20개`, `🎥 동영상 Y/5개`) 탑재
* **미디어 갤러리 프리뷰**: 썸네일 그리드, 타입 뱃지(IMG/VID), 개별 삭제(×) 및 전체 비우기 지원
* **이미지 켄 번스(Ken Burns) 모션**: 사진도 멈춰있지 않고 서서히 줌인(`1.0x -> 1.15x`)되어 역동적인 영상으로 표현

### 5. 세로형 9:16 모션 비주얼 & 가라오케 자막 엔진
* **1080 x 1920 해상도**: 유튜브 쇼츠 최적화 규격
* **가라오케 단어별 하이라이트 자막**: 현재 읽히는 단어에 실시간 형광 노랑 하이라이트 부여
* **진행 바(Progress Bar) & 헤드라인 배너**: 영상 상단 시선 고정 타이틀 및 상단 시간 진행 게이지 바
* **마스터 오디오 믹싱**: 나레이션 전용 오디오(.mp3) + 내장 BGM + 효과음(SFX) 스트림 완벽 합성
