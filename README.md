# 유튜브 쇼츠 자동생성기 (ShortsMaker) v2.7

> 웹 브라우저 상에서 원클릭으로 9:16 세로형 유튜브 쇼츠(Shorts) 영상을 기획, 제작, 렌더링 및 다운로드하는 자동화 파이프라인 웹 애플리케이션입니다. 렌더링 시 실시간으로 화면이 재생되고 한국어 TTS 음성과 BGM/SFX가 동시에 인코딩되며, 모든 조작 및 기능 설명 줄에 `[안내]` 표준 표기가 일관되게 적용되어 한눈에 기능을 쉽게 파악할 수 있습니다.

* **프롬프터 파일**: `쇼츠프롬프터.TXT` (UTF-8)

## 🚀 주요 기능 명세 (v2.7 Standardized [안내] Guidance)

### 1. 조작 및 기능 설명 줄 [안내] 표준 표기 일괄 적용 - New!
* 기능 고유 명칭과 버튼, 입력 컨트롤의 모드는 온전히 유지하면서, 각 기능 아래에 위치한 부가 설명 텍스트 라인에 `[안내]` 태그를 일관되게 통일 적용하였습니다.
* 적용 영역:
  * **1. 대본 기획**: 배경음+나레이션 동시 믹싱 녹음 안내
  * **2. 배경/비주얼**: 올인원 미디어 업로더 다중 선택 안내, 미등록 시 가이드 안내, 자동 순차 교체 안내
  * **4. 오디오 믹싱**: 실시간 마이크 낭독 녹음 안내, MP3 음원 업로드 안내
  * **다운로드 설정 모달**: 브라우저 TTS 녹음 안내, 저장 방식 선택 안내, 각 저장 방식 상세 안내
  * **작업 히스토리 모달**: 스냅샷 저장 안내, 프로젝트 목록 수정/개선 안내, 빈 히스토리 안내

### 2. 렌더링 시 실시간 화면 재생 및 TTS 음성 동시 인코딩 파이프라인
* **보여지고 들리는 그대로 비디오 저장**:
  * 렌더링을 시작하면 화면이 멈추지 않고 실시간으로 씬 전환, 가라오케 자막, 켄번스 줌 애니메이션이 재생됩니다.
  * 씬마다 브라우저의 한국어 TTS 음성이 스피커를 통해 자연스럽게 울려 퍼지며, BGM 및 효과음(SFX)과 함께 최종 비디오 파일(`.webm`)에 100% 동시 녹음됩니다.
  * 렌더링 진행률(프로그레스 바)과 씬 하이라이트가 영상 타임라인과 완벽히 동기화되어 렌더링 완료 시 자동으로 다운로드됩니다.

### 3. 모니터 화면 맞춤 컴팩트 세로 레이아웃
* 다운로드 모달 50% 슬림화, 저장 방식 가로 3분할 콤팩트 그리드 개편, 폰 목업 세로 높이(515px) 최적화로 모니터 한 화면에 스크롤 없이 100% 안착.

### 4. 작업 히스토리 저장 관리 및 복원(재수정) 시스템
* 1. 대본기획, 2. 배경 미디어 풀, 3. 자막 스타일, 4. 오디오 믹싱의 모든 상태를 스냅샷으로 보관하고 클릭 한 번으로 당시 상태를 100% 복원하여 재수정 가능.

### 5. 내장 신디사이저 BGM 테마 10종 확충
* 쇼츠 분위기에 맞춘 10가지 Web Audio 사운드 프리셋 탑재 (로파이 힙합, 신스웨이브, 사이버펑크, 어쿠스틱 드림, 업비트 팝, 미스터리 앰비언트, 긴장 스릴러, 쇼츠 트랩, 피아노 무드, 시네마틱 에픽)
