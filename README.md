# 유튜브 쇼츠 자동 제작기 (ShortsMaker) v2.1 Narration Interceptor

> 웹 브라우저 상에서 원클릭으로 9:16 세로형 유튜브 쇼츠(Shorts) 영상을 기획, 제작, 렌더링 및 다운로드하는 자동화 파이프라인 웹 애플리케이션입니다. 폰트 위치/사이즈/부분강조색을 마음대로 조절할 수 있으며, 다운로드 영상에 나레이션 멘트가 누락되지 않도록 도와주는 스마트 인터셉터 및 실시간 마이크 낭독 녹음 파이프라인을 지원합니다.

## 🚀 주요 기능 명세 (v2.1 Narration Interceptor 고도화)

### 1. 다운로드 시 나레이션 멘트 누락 방지 스마트 인터셉터 - New!
* **나레이션 미등록 경고 & 원클릭 해결창**:
  * 나레이션 음성 파일이 없는 상태에서 비디오 다운로드 클릭 시, 무음으로 그냥 내려받지 않도록 경고창을 띄우고 **`[🎙️ 내 목소리로 바로 녹음하기]`** 숏컷 버튼을 제공합니다.
* **상단 플로팅 실시간 녹음 바**:
  * 마이크 녹음 중일 때 화면 상단에 붉은색 플로팅 바가 나타나며, 화면의 노란 가라오케 자막을 따라 읽은 뒤 원클릭으로 녹음을 마치면 비디오에 100% 디지털 합성됩니다.
* **대본 탭(1번 탭) 나레이션 녹음/등록 바 전면 배치**:
  * 대본 입력창 바로 아래에 배치되어 대본을 생성하자마자 바로 목소리를 입힐 수 있습니다.

### 2. 자막 폰트 위치, 크기, 부분 폰트 색상 정밀 커스텀
* **📍 폰트 세로 위치 (Y축) 자유 이동**: 퀵 버튼(상단 22%, 중앙 50%, 하단 70%) 및 15%~85% 정밀 슬라이더
* **📏 폰트 크기 조절**: 36px ~ 120px 실시간 가변 슬라이더
* **🌟 부분 폰트(가라오케 하이라이트) 색상 변경**: 현재 읽는 단어 강조 컬러칩 5종 및 커스텀 컬러 피커
* **⚪ 기본 텍스트 색상 & ⬛ 외곽선 테두리**: 텍스트 컬러 선택 및 외곽선 테두리 두께(0~24px)와 색상 조절

### 3. 비디오 렌더링 마스터 오디오 스트림 합성
* 신스 BGM 비트/앰비언트 루프 및 씬 전환 효과음(Whoosh, Pop) 결합
* `audioBitsPerSecond: 128000` 고음질 인코딩

### 4. 음식점 전문 쇼츠 시나리오 2종
* 🍽️ 신규 오픈 맛집 안내 (장소/위치, 오픈 할인 이벤트)
* 🥩 시그니처 대표 메뉴 소개 (비주얼/식감 묘사, 품절 주의 훅)

### 5. 다운로드 경로 및 파일명 직접 지정 UI
* 💻 PC 파일 탐색기 저장 폴더(경로) 직접 선택 (`showSaveFilePicker`)
* 📱 모바일 '내 파일/파일 앱/클라우드' 저장 연동 (`navigator.share`)
